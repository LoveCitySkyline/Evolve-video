# 一次性复核剩余的物理事实

V37.1 的离线审计按保存的响应计数。同一视频的初评和增强复核会重复出现，因此 `claims_withheld: 5` 不表示五个独立视频。新工具把这些响应按候选视频哈希、源任务、事实定义去重，生成可在本地浏览器打开的证据包。它不调用模型、不生成视频、不修改旧评分，也不改变 V37.1 评估协议。

## 在服务器导出

在仓库根目录执行一条命令，不需要先设置输出变量或运行 `test.py`：

```bash
PYTHONPATH=src python scripts/prepare_predicate_review.py --run-dir outputs/h3_qwen38_v35_batch_RhHC8Q
```

工具自动创建与原运行目录并列的新目录，打印 `review_dir` 和 `report`。把 **整个 review_dir 文件夹** 下载到电脑，打开其中的 `index.html`；只下载 HTML 会丢失画面。页面无需联网，隐藏模型结论、置信度和解释，保留源命题、身份定义、原视频时间、缓存裁片、边界帧和逐帧证据。同一事实的不同取样视图并列显示。

只判断当前命题。例如“链条啮合”与“链条松弛”分别判断，“操作机构”不能代替“车轮转动”。画面无法区分就选择“证据不足 / 看不清”，不要为了清空未知而选择不符合。这里复用缓存的采样证据，不能保证原视频的细微运动都已保留。

填写标注人、标签和证据说明后，点击“导出人工标签 JSON”。浏览器会下载 `human-labels.json`，把它放回 review_dir 文件夹。未完成项可以保持未标注；页面不自动保存，关闭前需要导出。

## 检查标签

把标签放回导出目录后，执行工具打印的 `after_saving_human_labels_command`。这条命令已经填写实际目录，无需自己设置变量。

也可通过 `--labels` 指定下载文件位置。标签与证据包指纹绑定，导入时再次核对图片、裁片哈希。视频、命题或画面改变后不能复用旧标签。人工未知独立计数，不能转换成零分。每个视频事实只计一次；初评与增强复核意见不投票。

## 输出含义与边界

- `cases.json`、`index.html`：待核对命题和经过哈希校验的媒体，隐藏模型回答。
- `model-audit.json`：独立保存原回答、触发原因与来源。建议完成盲标后再看。
- `manifest.json`：去重数量、媒体缺失或哈希问题、历史纠正记录和未解决的响应错误。
- `labels-template.json`：空标签模板；不会替用户填写真值。

只有存在明确的 `.correction-1.raw.json` 且纠正回答能通过当前离线解析和身份检查，初始响应才列为 `superseded_attempts`。缺少有效纠正的记录仍列为 `unresolved_attempts`，不能自动丢弃越界引用。这里识别的是保存的纠正链，不代表整次实验的最终结果已修复。

复核项来自历史被拦截回答，属于开发诊断候选，未必是最终判断中的未决错误。工具不会把没有命中英文规则的回答宣称为正确。导出只复制运行目录中哈希匹配的缓存媒体，缺失或变化会明确报告，不偷偷替换画面。

这批样本经过问题筛选，不能代表整体准确率，不能用于宣称未见测试集收益。人工标签用于建立固定的开发回归依据；本工具仅汇总，不自动写入 verifier 的实验评分或覆盖未知。即使人工标签与旧模型结论一致，也不能证明旧解释使用了正确的推理。

## 同步与测试

运行同步 `src/evovideo_skill/` 和 `scripts/`；开发验证同步 `tests/` 和 `docs/`。配置、benchmark、视频与权重无需改动。

```bash
PYTHONPATH=src:tests python -m unittest test_predicate_review_pack test_predicate_evidence
```

测试覆盖按视频/任务/事实去重、有效纠正与未解决格式错误、媒体与标签绑定、未知标签独立统计、原文件不变、盲标页面隔离模型理由以及单命令导出。这些是程序行为验证，不是视觉准确率测试。
